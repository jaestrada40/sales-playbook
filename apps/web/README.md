# Sales Playbook Web

Frontend React + Vite del asistente de llamadas Sales Playbook.

## Desarrollo

```powershell
pnpm install
pnpm start
```

La aplicación queda disponible en `http://localhost:4200`.

## Comandos

- `pnpm start`: servidor de desarrollo.
- `pnpm run build`: compilación de producción.
- `pnpm run lint`: verificación TypeScript.
